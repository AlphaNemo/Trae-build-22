# shared/contract.md — 接口契约

> **作用**：定义模块之间的接口，**冻结后各模块并行开发**。
> **状态**：模板（赛题未知，现场定题后按下文模板填写）。
> **原则**：**先冻结，再开发**；任何人改动都要**在群里广播**。

---

## 1. 使用方式

1. 现场定题后，**10 分钟内**把用到的接口按第 4 节模板填好。
2. 字段名**大小写敏感**，前后端必须完全一致。
3. 冻结后本文件**只读**；`ui/`、`logic/`、`ai/` 各自照此实现，不互相等待。
4. 接口未实现时，先用 `shared/mock.md` 的假数据顶着。

---

## 2. 通用约定（统一，别各写各的）

| 项 | 约定 |
|---|---|
| 命名风格 | **snake_case**（如 `image_url`、`user_text`） |
| 编码 | UTF-8 |
| 时间 | ISO 8601 字符串，如 `2026-10-11T13:00:00+08:00` |
| ID | 字符串 |
| 空值 | `null` |
| 布尔 | `true` / `false` |
| 错误结构 | `{ "error": { "code": "string", "message": "string" } }` |

**AI 相关接口统一形状**（便于替换模型）：

```
输入：{ "input": <文本/文件引用>, "options": {...} }   // options 可选
输出：{ "result": <文本/结构化数据>, "meta": {...} }    // meta 存耗时/模型名等
```

## 4. 接口模板（复制即用）

### `<接口名>`

- **方法 / 路径**：`POST /xxx`
- **负责模块**：`ai/` 或 `logic/`
- **输入（Request）**

  | 字段 | 类型 | 必填 | 说明 |
  |---|---|---|---|
  | `field_a` | string | 是 | … |

- **输出（Response）**

  | 字段 | 类型 | 说明 |
  |---|---|---|
  | `field_b` | string | … |

- **示例**

  ```jsonc
  // Request
  { "field_a": "示例" }
  // Response
  { "field_b": "结果" }
  ```

- **错误**：`{ "error": { "code": "...", "message": "..." } }`
