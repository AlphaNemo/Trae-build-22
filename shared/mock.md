## 3. TTS 朗读规范（与方案 `speak()` 代码一致）

- 拼接顺序：`药名。dose。freq。timing。` + （warning 存在时）`注意：warning。`
- `lang = 'zh-CN'`，**`rate = 0.85`（刻意慢速，老人友好，不许改）**
- 朗读前必须 `speechSynthesis.cancel()` 防连点叠音
- 按钮状态文案：`🔊 念给我听` → 朗读中 `正在朗读…` → 结束 `🔁 再念一遍`
- 无 `speechSynthesis` 的浏览器 → 降级「逐行高亮 + 字幕滚动」，不报错

## 4. 异常与兜底话术

| 场景 | 处理 | 话术/文案 |
|---|---|---|
| TTS 没声音（最高危翻车点） | 逐行高亮 + 字幕滚动；用提前录好的演示视频顶上 | 屏幕大字本身就是兜底，不说「失败」 |
| 老人「拍不清」（产品内兜底） | 假拍照页底部常驻链接跳常用药选择 | 「拍不清楚？从常用药里选 →」 |
| 评委问「数据是假的」 | 直答预置药库 + 生产版两方向 | 「预置 8 种常见药库；生产版对接国家药品目录，或扫药盒追溯码」 |
| 评委问「手机放大镜就行」 | 直答看懂 ≠ 看清 | 「放大镜只解决看得见，我们直接给出结构化三行——这是看懂」 |
| 责任边界（评委必问） | 立场话术 | 「只做翻译，不做诊断、不做剂量推荐、不替代医嘱；识别不到就降级手动选药，宁可不答，不能答错」 |
